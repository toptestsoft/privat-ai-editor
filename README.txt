📖 Руководство пользователя: Приватный ИИ-редактор текста
Что это: инструмент для сокращения, перефразирования, перевода и анонимизации текста с помощью ИИ. Работает полностью локально — ваши данные не покидают компьютер.

🚀 Быстрый старт (30 секунд)
У вас есть…	Что делать
LM Studio или Ollama	Откройте файл двойным кликом → вкладка «🏠 Мой LM Studio» → «Проверить» → «Загрузить список» → выберите модель → готово
Ничего не установлено	Откройте файл через локальный сервер (см. ниже) → вкладка «🌐 Браузерная модель» → выберите Qwen 2.5 0.5B → «Скачать» → готово
Шаг 1: Первый запуск
Сохраните файл editor_v4.3.html на компьютер (например, на Рабочий стол).
Откройте его в современном браузере:
✅ Google Chrome 113+
✅ Microsoft Edge 113+
✅ Brave (последняя версия)
⚠️ Firefox — частичная поддержка (без WebGPU)
❌ Safari — не рекомендуется
Дважды кликните по файлу — он откроется как обычная веб-страница.
💡 Совет: Для браузерного режима (WebGPU) лучше запускать через локальный сервер, а не двойным кликом. Подробнее — в FAQ, вопрос 2.

Шаг 2: Выбор режима работы
В редакторе две вкладки. Выберите подходящую:

Вариант А: 🏠 Мой LM Studio / Ollama (рекомендуется для качества)
Использует мощную модель, запущенную на вашем компьютере.

Если у вас LM Studio:
Скачайте и установите LM Studio.
Загрузите текстовую модель. Рекомендуемые:
Qwen2.5-7B-Instruct — отличный русский язык
Llama-3.1-8B-Instruct — универсальная
Gemma-2-9B-It — хорошее качество
Перейдите во вкладку Server (значок <> слева) → нажмите Start Server.
⚠️ Обязательно: в настройках сервера включите CORS (Enable CORS).
В редакторе нажмите 🔵 Проверить. Зелёная точка = подключение установлено.
Нажмите 📥 Загрузить список → выберите модель из выпадающего списка.
Если у вас Ollama:
Установите Ollama.
Загрузите модель: ollama pull qwen2.5:7b-instruct
Запустите с разрешением CORS:
BASH




# Windows (PowerShell):
$env:OLLAMA_ORIGINS="*"; ollama serve

# macOS / Linux:
OLLAMA_ORIGINS=* ollama serve
В редакторе укажите эндпоинт: http://127.0.0.1:11434/v1
Нажмите 🔵 Проверить → 📥 Загрузить список.
Вариант Б: 🌐 Браузерная модель (WebGPU) (без установки программ)
Модель работает прямо в браузере. Идеально для быстрых задач.

Переключитесь на вкладку 🌐 Браузерная модель (WebGPU).

Выберите модель из сетки:

Модель	Размер	Для чего
⭐ Qwen 2.5 0.5B	~1 ГБ	Лучший баланс: быстрая, понимает русский
SmolLM2 135M	~300 МБ	Мгновенный старт, для проверки
Llama 3.2 1B	~2.5 ГБ	Выше качество, медленнее
Phi-3.5 mini	~8 ГБ	Самая умная, для терпеливых
Нажмите 📥 Скачать выбранную модель.

При первом запуске браузер скачает файлы модели (1–3 минуты). В следующий раз — мгновенно из кеша.

⚠️ Важно: Браузерный режим не работает из file:// (двойной клик по файлу). Нужен локальный сервер. См. FAQ, вопрос 2.

Шаг 3: Работа с текстом
Вставьте текст в поле «Исходный текст».

Лайфхаки:

Перетащите файл .txt или .md в пунктирную область
Нажмите 📖 Вставить пример для демонстрации
Выберите действие:

Действие	Что делает
✂️ Сократить текст	Убирает воду (сила: слегка / вдвое / максимум)
🔁 Перефразировать	Переписывает другими словами
🎯 Выделить ключевое	Маркированный список главных мыслей
🌍 Перевести	Перевод на выбранный язык
🕶 Анонимизировать	Заменяет ФИО, телефоны, адреса на [ИМЯ], [ТЕЛЕФОН] и т.д.
✏️ Исправить грамматику	Корректура без изменения смысла
💼 / 😊 / 🧒 Тон	Деловой / дружелюбный / простой стиль
⚙️ Свой промпт	Любая инструкция + сохранение в пресеты
Настройте Креативность:

Точный (0.1) — строгое следование фактам
Сбалансированный (0.4) — оптимально для большинства задач
Креативный (0.8) — более вольный стиль
Нажмите ▶ Запустить или Ctrl + Enter.

После генерации результат появится в нижнем поле. Доступные действия:

Кнопка	Что делает

❓ Частые проблемы и решения (FAQ)
1. Ошибка: «LM Studio не отвечает» или «timeout»
Решение:

Убедитесь, что сервер запущен: в LM Studio → Server → Start Server (горит зелёным).
Проверьте, что включён CORS (Server Settings → Enable CORS).
Убедитесь, что эндпоинт в редакторе: http://127.0.0.1:1234/v1.
Попробуйте нажать 🔵 Проверить ещё раз.
Для Ollama: убедитесь, что запущено с OLLAMA_ORIGINS=*.

2. Ошибка: «Запуск невозможен из file://»
Причина: Браузеры блокируют WebGPU и загрузку больших моделей из локальных файлов по соображениям безопасности. Это ограничение всех браузеров, не баг редактора.

Решение для Windows:

Создайте рядом с editor_v4.3.html файл start.bat с содержимым:

BAT




@echo off
chcp 65001 >nul
cd /d "%~dp0"
echo Запуск сервера... Откроется через 2 секунды.
start /b cmd /c "timeout /t 2 /nobreak >nul && start http://localhost:8000/editor_v4.3.html"
python -m http.server 8000
pause
Дважды кликните по start.bat. Требуется установленный Python (при установке поставьте галочку «Add to PATH»).

Решение для macOS / Linux:

BASH




cd ~/Desktop  # папка с файлом
python3 -m http.server 8000
# затем откройте http://localhost:8000/editor_v4.3.html
Альтернатива: Вкладка «🏠 Мой LM Studio» работает прямо из файла, без сервера.

3. Генерация идёт очень медленно
Причины и решения:

Причина	Решение
Слабая/отсутствует видеокарта	Браузер автоматически переключился на CPU — это медленнее. Используйте режим LM Studio.
Слишком большая модель	Для браузерного режима берите модели до 1B параметров. Для LM Studio — до 8B.
Очень длинный текст	Тексты > 15 000 символов обрабатываются долго. Разбейте на части.
Первый запуск браузерной модели	Модель скачивается. Подождите 1–3 минуты, дальше будет быстро.
4. Модель «болтает»: пишет «Конечно, вот ваш текст…» вместо результата
Решение:

Используйте модели с суффиксом Instruct или Chat в названии.
Снизьте Креативность до «Точный».
Для Qwen3-моделей редактор автоматически отключает «размышления» (thinking).
Если не помогает — попробуйте другую модель.
5. Кнопка «📥 Загрузить список» не показывает модели
Решение:

В LM Studio: убедитесь, что модель загружена в память (не просто скачана, а выбрана в чате).
В Ollama: выполните ollama list в терминале — модель должна быть в списке.
Нажмите «📥 Загрузить список» повторно.
6. Не работает кнопка «📋 Копировать»
Причина: Браузер блокирует доступ к буферу обмена на file://.

Решение: Запустите через локальный сервер (см. вопрос 2) или выделите текст вручную и нажмите Ctrl+C.
